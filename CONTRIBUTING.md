# Contributing

Thanks for helping! Contributions of all sizes are welcome: typo fixes, better prompts, new templates, legal notes for more countries.

## Good first contributions

- **Templates** – a new landing page design in `template/` style (static HTML/CSS, `{{PLACEHOLDERS}}`, demo label, no third-party images). Add it as a folder under `templates/<name>/` with its own README; users copy the design they like into their project's `template/` folder.
- **Countries** – add or correct a row in the legal table (in both `SKILL.md` and `README.md`) with a link to the source law or regulator guidance.
- **Local directories** – business directories that work well for finding prospects in your country.
- **Examples** – a fictional example run in another language under `examples/`.

## How to contribute

1. Fork the repository and create a branch.
2. Make your change. Keep `SKILL.md` and `README.md` consistent with each other.
3. If you change the skill's behaviour, try it in Claude Code on a small run (1–2 candidates) and describe the result in the pull request.
4. Open a pull request with a short description of what and why.

## Ground rules

The project exists to help freelancers offer genuine help, not to spam. Changes that weaken these rules will not be merged:

- nothing is sent or published without the user's confirmation
- no bulk mailing; every message is individual
- only verified facts; nothing is invented about a business
- demos are always labelled and `noindex`
- the recipient country's law takes precedence
- examples and test data use fictional businesses only (`.example` domains, reserved phone numbers)

## Reporting issues

Open an issue with what you asked Claude, what happened and what you expected. Please remove any real contacts or personal data from logs before posting.
